Markup contract

Use .input-hint as the wrapper, .ds-keycap for text controls, .input-hint__icon for prompt assets, and .input-hint__label for the action.

Layer behavior

Position
Bottom safe-area, centered, flexible wrap.
Tone
Low-contrast parchment over a dark gradient scrim.
Joiners
Hidden in the game layer; use spacing instead of slashes.
Clickable
Only menu/start/end hints become buttons.

Implementation notes

  • Runtime actions are defined by src/app/ui/hint-layer.js; binding labels and asset paths come from src/app/input/input-hints.js.
  • Current production game style intentionally desaturates prompt SVGs for a moonlit parchment look.
  • Keep labels action-first: Jump, Dash, Level Select. Avoid instructional sentences in the bottom layer.
