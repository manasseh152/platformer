Markup contract

Root
#hud.ds-hud is the in-game status container.
Level name
#hudLevelName is written by syncGameplayHud.
Health
#hearts contains five .heart nodes; .full tracks HP.
Dash
#dashStatus.ready switches copy and success color.
Timer
#speedRunHud is hidden unless speed-run mode is enabled.

Placement rules

Anchor
Top-left safe-area with 18px + env(safe-area-inset-*).
Width
About 310px; collapse only by viewport, not content.
Pointer
HUD is non-interactive: pointer-events: none.
Tone
Translucent dark card over gameplay, not a decorative page panel.
