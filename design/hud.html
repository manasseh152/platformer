Markup contract

Run status
#hud.hud-card.ds-hud owns level, health, objective, and dash state.
Level name
#hudLevelName is written by syncGameplayHud.
Health
#hearts contains five .heart nodes; .low-health strengthens danger.
Dash
#dashStatus.ready uses a small success marker.
Speedrun
#speedRunHud.speedrun-hud is a separate top-right primitive, not a row inside run status.

Placement rules

Run anchor
Top-left safe-area with 18px + env(safe-area-inset-*).
Speedrun anchor
Top-right safe-area; may fall to bottom/left on narrow screens.
Width
Status about 310px; speedrun about 270px.
Pointer
HUD primitives are non-interactive: pointer-events: none.

Implementation notes

  • Runtime state sync lives in src/app/ui/gameplay-hud.js.
  • Production styles remain untouched for this pass.
  • This page updates the design contract from one stacked card to separate floating HUD primitives.
