Implementation notes

DOM source
src/scenes/menu-dom.js owns start and pause shell markup.
Behavior
src/app/ui/menu/menu-shell.js, menu-input.js, and menu-setup.js wire state, focus, and controller actions.
Shared primitives
styles/ui-tokens.css and styles/ui-primitives.css define .ds-screen, .ds-panel, .ds-button, .ds-title, chips, keycaps, focus, and menu scale tokens.
Game styling
styles/main.game.css specializes start, pause, level-select, settings, and page transition layouts.
Design reference only. Keep page styling neutral so menu decisions remain isolated.
