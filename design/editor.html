Composition

Canvas
Full viewport, pixelated, dark enough to support grid and terrain contrast.
Topbar
Fixed, three-part layout: main menu, tabs, preview/save actions.
Panel
Left overlay, glass surface, compact sections with scrollable tab content.
Hints
Instructional prompts are supplied by the shared hint system, not this editor surface.

Authoring states

Selected layer
[aria-pressed="true"] gets accent border and soft fill.
Brush
Current brush uses an outline rather than changing tile color.
Save state
[data-save-state] labels: saved, dirty, saving, invalid.
Focus
Controller focus uses a visible focus ring from UI tokens.

Implementation notes

  • Production markup lives in editor.html; behavior in src/editor/map-editor.js, src/editor/editor-viewport.js, src/editor/editor-history.js, and src/editor/map-editor-commands.js.
  • Production styles live in styles/main.editor.css and import shared tokens from styles/ui-tokens.css and styles/ui-primitives.css.
  • Keep editor styling functional: authoring surfaces, state feedback, and input affordances should be clearer than atmosphere.
