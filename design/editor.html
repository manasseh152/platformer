Composition

Full viewport, pixelated, dark enough to support grid and terrain contrast.

Fixed, three-part layout: main menu, tabs, preview/save actions.

Authoring states

Selected layer
[aria-pressed="true"] gets the same filled accent treatment as production.
Selected pack
Packs sit between Layers and Pack assets, using the same switcher language.
Brush
Current brush uses a high-contrast selected chip without changing the tile swatch.
Save state
[data-save-state] labels: saved, dirty, saving, invalid.
Focus
Controller focus uses an accent ring over the existing primitive.

Implementation notes

  • Production markup lives in editor.html; behavior in src/editor/map-editor.js, src/editor/editor-viewport.js, src/editor/editor-history.js, and src/editor/map-editor-commands.js.
  • Production styles live in styles/main.editor.css; this pass updates the design reference only.
  • Keep editor styling functional: authoring state, current tool, and input affordances should be clearer than atmosphere.
