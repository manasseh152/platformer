# Realign project boundaries around ECS-ish scene architecture

The project had several architecture generations mixed together: reusable primitives, platformer rules, authored content, catalog entries, browser app glue, and rendering code crossed boundaries freely. We chose to realign source ownership around explicit packages such as `engine`, `core`, `content`, `catalog`, `app`, `render`, `editor`, and `devtools` so the ECS-ish scene/object/component model could become the stable integration point without legacy level/catalog/content concepts living in core. Current package rules live in [`../patterns/source-layout.md`](../patterns/source-layout.md).
