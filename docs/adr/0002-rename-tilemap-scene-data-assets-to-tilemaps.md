# Rename tilemap scene data assets to tilemaps

Tilemap data was previously described with names like `tilemapScene`, which blurred authored spatial layouts with runtime scene lifecycle components. We chose **Tilemap** for authored tile layers and placed assets, **Scenario** for launchable entries, and runtime scene terminology only for implementation lifecycle components so gameplay/content docs do not imply that a tilemap is itself a runtime scene. Current domain language lives in [`../../CONTEXT.md`](../../CONTEXT.md), and current tilemap authoring guidance lives in [`../patterns/tilemaps.md`](../patterns/tilemaps.md).
