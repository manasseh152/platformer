# Contained terrain scale and collision pipeline

Terrain needed one auditable source of truth for authoring, visuals, and collision so rendered ground/walls never imply walkable or blocking space that differs from gameplay. We chose three explicit scales: 32px gameplay placement grid, 16px terrain authoring/autotile cells, and 8px derived collision primitives that can be merged into physics rects; contained terrain visuals must stay inside authored terrain cells. Current terrain and tilemap authoring guidance lives in [`../patterns/terrain.md`](../patterns/terrain.md) and [`../patterns/tilemaps.md`](../patterns/tilemaps.md).
